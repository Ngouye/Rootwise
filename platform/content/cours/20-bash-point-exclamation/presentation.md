`!!`, `!$`, `^a^b^`, `:p`, `[ ! -d ]`, `if !`, `!(motif)`, `${!var}`… Ce simple caractère cache **deux
mécanismes** que beaucoup ignorent pendant des années : l'**expansion de l'historique** dans le
terminal, et la **négation** dans le langage.

Ce cours reprend le guide pratique de **Ngouye GNING** : 15 fiches testées sous **Bash 5.2**, les pièges
à éviter et les réflexes pour utiliser le `!` sans risque.

- **Rappeler** n'importe quelle commande de l'historique sans la retaper ;
- **réutiliser et transformer** les arguments des commandes précédentes ;
- **éviter les pièges** : prévisualiser avant d'exécuter, corriger l'erreur « event not found » ;
- **maîtriser la négation** dans les scripts : tests, codes de retour, motifs d'exclusion, expansion indirecte.

*Guide pratique · Administration Linux — version 1.0, octobre 2026. Le guide complet en PDF est
disponible à la fin du cours.*
